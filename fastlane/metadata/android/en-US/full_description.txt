Cayley is an Android distribution of Group Explorer, free software for learning and exploring finite groups through interactive visualizations.

The inherited Group Explorer work is by Ray Ellis and Nathan Carter. This fork adds Android/mobile packaging and experimental symmetry-pattern visualization while preserving the original project attribution and LGPL v3 licensing. The upstream project is https://github.com/nathancarter/group-explorer and the modified source used for this Android package is https://github.com/isomorphisms/Cayley.

The app includes Cayley diagrams, multiplication tables, cycle graphs, symmetry objects, group information, and the added planar symmetry-pattern view.

The APK bundles the modified Group Explorer source into an Android WebView package. Some inherited pages still request jQuery and Font Awesome from cdnjs at runtime, so those UI assets use network access. Three.js remains bundled under its included MIT license; other third-party components retain their own licenses. The GPL/LGPL license texts and provenance notice are bundled with the app source assets.
