# Mobile escape hatch

On small screens, Group Explorer should not reserve a permanent toolbar row for app-level destinations.

The current prototype uses **ƒ⁻¹** as a single persistent escape control. It is intentionally not Back or Undo. Interpreted as an inverse relation/preimage, one current visual state can expose several possible destinations.

Tapping ƒ⁻¹ expands the existing app-level destinations; tapping it again collapses them. The mathematical controls for the current visualization remain separate.

This is provisional notation. If exploration of the group-theoretic interaction model suggests a better symbol, the symbol can change without changing the interaction contract.
