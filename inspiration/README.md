# Inspiration

This directory collects source material that Group Explorer may learn from later. For now the purpose is simply to keep useful explanations visible and close to the project; nothing here has yet been incorporated into Group Explorer's mathematical or interaction design.

Every work remains the work of its credited author or authors. Vendored copies are kept unmodified and their original sources are recorded. Inclusion does not transfer copyright, imply endorsement, or assert a broader license than the author or publisher actually grants.

`Vendored` below means the PDF itself is in this directory. `Source only` means the work belongs in this reading/inspiration set, but this pass did not find sufficiently explicit permission for us to republish the whole PDF in a public GitHub repository. A public download plus attribution is not treated as a redistribution license.

### T. J. Sullivan — *The First Isomorphism Theorem*

- Status: **Source only**
- Author: T. J. Sullivan
- Source: https://www.tjsullivan.org.uk/pdf/morphthm2014.pdf
- This is the cows-and-pens explanation: cows are grouped into pens according to the market to which they are sent, before the same idea is transferred to the isomorphism theorem.
- This is the source I found matching the remembered cows/pens essay. Its own title is specifically *The First Isomorphism Theorem*; the index does not inflate that into a claim that this PDF itself covers all three isomorphism theorems.

## Rights and provenance

- Keep vendored PDFs unmodified. If we later annotate, excerpt, redraw, or adapt something, put that derivative work in a different file and credit the exact source beside it.
- Record the canonical or author-hosted source even when a local copy is present.
- Attribution is not a substitute for a license. No broader permission is asserted merely because a PDF was publicly downloadable.
- MIT OpenCourseWare material above is attributed under MIT's stated CC BY-NC-SA 4.0 terms unless the individual resource states otherwise.
- Hatcher's stated noncommercial copying permission is recorded above.
- For the source-only works, the index deliberately preserves authorship and provenance without republishing the complete work. If explicit redistribution permission turns up later, change the status to `Vendored`, add the unmodified PDF, and record the permission source here.

The point of this directory is deliberately generous provenance: when an idea eventually reaches Group Explorer, we should be able to trace not only the theorem but the particular explanation, picture, analogy, lecture, mentor, editor, host, or course that helped make it understandable.
